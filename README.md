# Metronome

A web metronome built with React, TypeScript, and Vite. The application uses the Web Audio API to generate precise clicks in the browser and can be installed as a Progressive Web App (PWA) on compatible devices.

## Features

- Tempo control from 20 to 300 BPM, with manual adjustment and Tap Tempo.
- Time signature, beat unit, and 1 to 8 subdivision configuration.
- Subdivision pattern editor with accents, normal clicks, and mutes.
- Visual indicators for the current beat, subdivision, and measure.
- Progressive tempo mode, with automatic BPM increases up to a maximum.
- Training mode that alternates between audible and silent measures.
- Preset creation, selection, updating, and deletion.
- Presets stored locally in the browser using `localStorage`.
- PWA installation with a standalone window and automatic updates.

## Requirements

- Node.js 20.19+ or 22+
- npm
- A browser with Web Audio API and PWA installation support

## Run locally

```bash
npm install
npm run dev
```

Open the URL displayed by Vite, usually `http://localhost:5173`.

Audio starts when the metronome is enabled, subject to the browser's autoplay policies.

## Install as an app

The PWA must be accessed over `https` in production. `localhost` is also treated as a secure origin for development.

### Android and desktop

1. Open the application in Chrome or another compatible browser.
2. Use **Install app** or **Add to home screen** from the browser menu.
3. Confirm the installation.

### iPhone and iPad

1. Open the application in Safari.
2. Tap **Share**.
3. Select **Add to Home Screen** and confirm.

After installation, Metronome opens in its own window without the usual browser interface. The service worker and manifest are generated by `vite-plugin-pwa` during the build.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Starts the development server with hot reload. |
| `npm run build` | Type-checks the project and generates the production build in `dist/`. |
| `npm run preview` | Serves the production build locally. |
| `npm run lint` | Runs ESLint. |
| `npm test` | Runs the tests once with Vitest. |
| `npm run prepare` | Initializes Husky in the local checkout. |

## Quality and CI

Husky runs `npm run lint` and `npm test` before every commit through `.husky/pre-commit`.

The GitHub Actions pipeline in `.github/workflows/ci.yml` runs on pushes to `main` and pull requests. It installs dependencies with `npm ci` and runs lint, tests, and the production build.
